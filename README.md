# SmartTour-BigData
Repositorio para la práctica SmartTour del modulo Big Data Aplicado (BDA) del CEGS - Inteligencia Artificial y Big Data

Este proyecto tiene como fin analizar datos turísticos mediante tecnologías Big Data.

## Tecnologías

- Python
- Docker
- JupyterLab
- Pandas

## Instalación

docker compose up

## Objetivo

Analizar demanda turística y crear cuadros de mando.
