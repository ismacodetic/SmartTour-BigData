# SmartTour-BigData
Repositorio para la práctica SmartTour del modulo Big Data Aplicado (BDA) del CEGS - Inteligencia Artificial y Big Data

Este proyecto tiene como fin analizar datos turísticos mediante tecnologías Big Data.

## Tecnologías

- Python
- Docker
- JupyterLab
- Pandas

## Instalación

docker compose up

## Objetivo

Crear una plataforma para analizar datos turísticos.
Analizar demanda turística y crear cuadros de mando.

## Estructura

datasets:
Datos utilizados en el proyecto.

scripts:
Programas Python.

notebooks:
Análisis realizados.

docs:
Documentación.
